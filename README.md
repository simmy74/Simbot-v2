# SIMBOT V2

Mobile-friendly EUR/USD technical-analysis starter.

## Files
- `server.js`: Express server and Twelve Data candle endpoint
- `index.html`, `styles.css`, `app.js`: dashboard and basic analysis
- `package.json`: Node.js dependencies and start command
- `.env.example`: example environment variables

## Run
1. Install Node.js.
2. Run `npm install`.
3. Set `TWELVE_DATA_API_KEY` in your hosting environment.
4. Run `npm start`.

The app is for analysis and paper testing only. It does not place trades. Third-party market data may differ from Pocket Option's candles and timing.
